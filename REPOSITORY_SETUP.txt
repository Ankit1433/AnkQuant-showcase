SETUP
1. FIRST: Switch https://github.com/Ankit1433/AnkQuant to Private using Settings > General > Danger Zone > Change repository visibility.
2. Visit https://github.com/new and create a Public repo named ankquant-showcase WITHOUT initializing README.
3. Upload README.md and the docs/ directory using Add file > Upload files (GitHub web uploads may not preserve folders from a ZIP; extract it first and drag in the files/folders).
4. Add the description, website and topics using the repo's About gear icon.
5. On https://github.com/Ankit1433 pin ankquant-showcase via Customize your pins.
6. Verify logged-out: showcase readable; original AnkQuant repo inaccessible.

SECURITY
If AnkQuant source was public before, existing clones/forks or caches may still exist. Rotate any credentials previously committed or published, and verify frontend bundles/network endpoints don't reveal protected logic.
